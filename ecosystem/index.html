Our own server

Every file is served from SWARM’s own infrastructure, with its SHA256SUMS beside it. No third party in between.

Source code(opens in a new tab)

Check the SHA-256 before you install. The Windows and Linux builds are not code-signed, so Windows SmartScreen will warn: More info → Run anyway. The Mac builds of SWARM Wallet and SWARM Messenger are not signed with an Apple Developer ID: macOS asks you to allow them once under System Settings → Privacy & Security → Open Anyway. SWARM Messenger is a first, unsigned release on every platform. SWARM Browser is an unsigned pre-release for Windows only. Android is a direct APK, debug-signed and installed by hand while the Google Play listing is pending; phones do not mine.

Testnet. The public testnet is still running and its builds are published in the Testnet section below. It is a different chain, its addresses start swarm1…, and its coins have no value.
