SWARM Wallet

Your wallet, wherever you are. Choose your platform to get started.

Windows and Linux wallet update

Version 0.1.0-mainnet.9 preserves the last loaded transfer history after a failed read, keeps the original error in Technical details, and explains when the wallet needs restarting. Fully quit SWARM Wallet before installing, then reopen it. If a payment was in progress, check its status after reopening before sending it again.

BEFORE YOU START

A little preparation.

Keep your recovery phrase backed up somewhere safe. Never share it.

Mobile wallets let you send and receive. Phones do not mine.

Need a hand? Get support →

Want to mine?

Explore SWARM Node →

Every build includes a SHA-256 checksum. Check it before you install, and only ever download from this site or the release repository.

TESTNET

The public testnet is still running.

SWARM mainnet is the real network, and everything above is a mainnet build. The public testnet stays online for testing: it is a different chain, its addresses start swarm1…, and its coins have no value and never will. Only install one of these if you know you want the testnet.
