What SWARM is

A currency, a network, and the software to run both.

SWARM is a new cryptocurrency, ticker SWM, with its own blockchain. It is secured by proof of work, its supply is fixed in the code, and every payment can be shielded so that sender, receiver and amount stay encrypted on-chain. It is built from open-source Zcash software — the parts that have been running real money for years — with the consensus rules and cryptography left exactly as they are.

The money

6.25 SWM per block, a block every 75 seconds, a halving every 1,680,000 blocks and a ceiling of 20,999,987.3152 SWM. No premine: the genesis block holds nothing, so every coin is mined. Of each block reward 80% goes to the miner and 20% to three published project destinations, block by block, for the life of the chain.

The software

SWARM Node runs a full node and mines with one click. SWARM Wallet holds, sends and receives, shielded or transparent, on desktop and phone. A public block explorer shows every block and every allocation. Underneath: the Zebra full node, the Zaino indexer and the Zingo wallet, forked from Zcash and open source.

The people

A founding team builds the software in the open. The network itself belongs to whoever runs a node and mines a block: there is no company server, no admin key, no account to apply for. The rules every node enforces are the same for the founders as for anyone else.

The privacy

Shielded transactions use zero-knowledge proofs, the same Orchard design Zcash uses, so the chain records that a valid payment happened without recording who paid whom or how much. Transparent payments exist too, and every wallet says plainly which kind you are about to make.

The mining

Proof of work is Equihash, the algorithm Zcash uses, with the inherited difficulty rule unchanged. The chain starts at minimum difficulty, so an ordinary computer finds blocks from the first day. Mining runs only when you press Start. As the network grows, difficulty rises and larger miners can join; nothing in the rules keeps anyone out.

The principles

Reuse proven code; never reinvent consensus or cryptography. Publish every rule, address and launch input before genesis. Nothing runs on your machine without your consent. No sale, no premine, no head start, no hidden treasury: every allocation is visible in every block.

Where SWARM is today

The public testnet has been running since 21 September 2026 with the final rules: the 75-second target, the 6.25 SWM reward, the 80 / 8 / 4 / 8 split paid in every block. Wallets for Windows, Linux, macOS and Android, the one-click mining app and the block explorer are all live. Test coins have no value and will not carry over.

Where SWARM is going

The mainnet is being built on the same code: a fresh genesis with zero coins in it, its own network identity so testnet and mainnet can never be confused, fresh keys for the three project destinations under a published custody policy, and an independent review before launch. There is no launch date until the gates are passed.

The Hive

A hive is just a lot of small jobs, done honestly.

SWARM borrows its shape from bees, because a beehive is the clearest picture of what a peer-to-peer network actually is: no boss, no central server, thousands of small contributions adding up to something none of them could manage alone.

Bees

Everyone running a node. Each one keeps its own copy of the rules and checks every block for itself, so nobody has to be trusted.

Foragers

The miners. They spend real electricity on proof of work to secure the chain. The work is Equihash and the chain starts at minimum difficulty, so ordinary computers can forage from the first block. Nothing in the rules keeps bigger miners out later.

Honey

The block reward. 6.25 SWM for every block found, paid for real work — never minted for anyone in advance.

Honeycomb

The blockchain. One cell for each block, sealed in order, each one referring back to the last — a shared ledger anyone can re-check.

The Hive

The peer-to-peer network itself. There is no central server to ask permission from. The more bees run nodes, the harder the hive is to switch off.

Shielded

Why SWARM

Old-fashioned ideas about money, built on proven code.

    Every payment can be transparent or shielded. Shielded transactions keep sender, receiver and amount encrypted on-chain, using zero-knowledge proofs. You decide, payment by payment.

  • Run by its community

    SWARM is developed in the open by its founding team and contributors. The network itself is run by whoever runs nodes and mines blocks — nobody needs permission to join, and the founders play by the same rules as everyone else.

  • Sound, predictable supply

    6.25 coins a block, halving every 1,680,000 blocks — about four years — up to a maximum of 20,999,987.3152 coins. The schedule is fixed in the code and published in full.

  • Proven foundations

    SWARM is built by forking open-source Zcash software — the Zebra full node, the Zaino indexer and the Zingo desktop wallet — with consensus rules and cryptography left unmodified.

  • Open source

    The node, the indexer and the wallet are all open source. Read the code, build it yourself, and check that it does what this page says it does.

Where each block reward goes

In every block, for the whole emission schedule. Each halving halves all four amounts together.

Of every block reward: 80% to the miner, 8% to Core Development, 4% to Grants & Ecosystem and 8% to the Community & Development Reserve. In era 0 that is 5.00, 0.50, 0.25 and 0.50 coins.

Fixed in the genesis rules for the whole emission schedule. Paid block by block as part of each block reward — not a premine.

At every halving

The block reward halves and the 80 / 8 / 4 / 8 split stays exactly the same. The percentages are fixed in the genesis rules and cannot be changed.

Over the whole life of the chain that is 80% to miners, 8% to Core Development, 4% to Grants & Ecosystem and 8% to the Community & Development Reserve.

In the last eras integer rounding retires the small streams first: Grants & Ecosystem rounds to zero from era 25, Core Development and the Reserve from era 26, and the miner keeps the remainder.

The reserve

Paid block by block to its own predefined address, like the other allocations. How it is governed and spent will be defined separately and published before mainnet launches.

The road to mainnet

No dates. Just the order of things.

Each stage has to be finished before the next one starts, and the evidence for each is published. We would rather be late than wrong about money.

  1. Done

    Engineering testnets

    Two closed networks proved the inherited proof of work, the per-block difficulty rule, chain reorganisation and recovery, and end-to-end shielded payments through the wallet.

  2. Now

    Public testnet

    Live since 21 September 2026 with the final economic rules. Wallets, the one-click mining app, an Android wallet and the block explorer are public. It stays online after mainnet as the place to rehearse upgrades.

  3. Now

    Mainnet engineering

    A distinct production identity: its own genesis, network magic and address prefix, so a mainnet wallet rejects testnet addresses and a transaction can never replay across networks. Separate production hosts. Custody tooling for the three destinations with a tested spend-and-recover path.

  4. Next

    Independent review and soak

    An external review of every change made on top of the upstream Zcash software, then weeks of the integrated launch candidate under normal and failure workloads: miners leaving, nodes restarting, partitions healing.

  5. Then

    Launch ceremony

    Keys for the three destinations generated offline and their public addresses published. Genesis derived from a public, unpredictable input so nobody — including us — can mine a head start. Signed releases and a published launch manifest anyone can verify.

  6. Finally

    Mainnet

    Block 1 is the first SWM ever issued, mined in public by whoever is running SWARM Node that day. No sale, no airdrop, no conversion of test coins. The date follows the evidence, not the other way round.

FAQ

Straight answers.

Is SWARM live?

The public testnet is live and has been since 21 September 2026: you can download the wallet and the node today, mine blocks and send shielded payments. The mainnet — the network whose coins are the real SWM — has not launched. It is being built on the same code and it launches only once the gates on the road to mainnet are passed.

There is no sale, no token offering and no launch date. When there is a date, it will be announced on this site and on the official channels only.

Do test coins have value? Will they carry over to mainnet?

No, and no. Test coins have no monetary value. They exist so the software can be exercised and broken safely. Mainnet starts from a fresh genesis with zero coins in it: no testnet balance, key or address is copied across, and there is no airdrop or conversion. Everything you learn on the testnet carries over; the coins do not.

What changes at mainnet, and what stays the same?

The same: the money. 6.25 SWM a block, 75-second blocks, a halving every 1,680,000 blocks, a ceiling of 20,999,987.3152 SWM, no premine, and the 80 / 8 / 4 / 8 split in every block. These rules already run on the public testnet and they carry over unchanged.

Different: the network. Mainnet gets its own genesis block, its own network identity and its own address prefix, so a mainnet wallet refuses a testnet address and a transaction can never replay from one network to the other. The three project destinations get fresh keys under a custody policy that is published before launch. The apps you use today get mainnet releases of their own. The full list is on the mainnet page.

How will the launch be fair?

Three ways, all checkable. The genesis block contains no spendable coins, so nobody starts with a balance. The genesis is derived from a public, unpredictable input that is fixed only at launch, so nobody can mine blocks in private beforehand and present them as a fresh start. And the rules, the three destination addresses and the launch manifest are published before block 1, so anyone can verify that the chain they are syncing is the one that was announced.

The 20% of each block reward that goes to the three project destinations is not a premine and not hidden: it is paid block by block, in public, for the whole life of the chain, and the percentages cannot be changed.

How does SWARM relate to Zcash?

SWARM is built by forking open-source Zcash software: the Zebra full node, the Zaino indexer and the Zingo wallet. The consensus rules and the cryptography are left unmodified; SWARM adds its own network definition, economics, apps and branding on top.

SWARM is an independent network with its own coin. It is not affiliated with or endorsed by the Electric Coin Company, the Zcash Foundation or Zingo Labs.

Can I mine with a normal PC?

Yes. The proof of work is Equihash and the chain starts at minimum difficulty, so SWARM is open to ordinary computers from the first block, on the testnet today and on mainnet at launch.

There is no promise that home computers stay competitive forever. As the network grows and difficulty rises, professional and specialised miners can join — and nothing in the rules keeps anyone out, at either end. Equihash hardware already exists, so that moment can come early. It is a consequence of keeping the rules open, and we say so rather than pretend otherwise.

SWARM Node lets you start and stop mining with one click. It only ever runs when you press Start, and it stops when you press Stop.

Is there a premine?

No. The genesis block contains no spendable coins, on the testnet today and on mainnet at launch. Every coin has to be mined, and mining rewards mature after 100 blocks before they can be spent.

Where do block rewards go?

Every block reward is split 80% to the miner who found the block, 8% to Core Development, 4% to Grants & Ecosystem and 8% to the Community & Development Reserve. That split runs for the whole emission schedule: each halving reduces all four amounts together and the structure never changes.

Each allocation is paid automatically to its predefined destination address. Destinations can only be changed through a formal protocol upgrade; the percentages themselves cannot be changed.

In the last eras integer rounding retires the small streams first: Grants & Ecosystem rounds to zero from era 25, Core Development and the Reserve from era 26, and the miner keeps the remainder.

No premine, no hidden treasury — every allocation is visible in every block. The full numbers are on the network page.

Who controls the three project destinations?

The project does. On the testnet each destination is a script address controlled by a single key, because test coins have no value. For mainnet the destinations get fresh keys, generated offline, held on separate devices under a threshold policy, with the spending and recovery procedure tested on disposable funds before the public addresses are fixed into the launch rules. That policy is published before launch. It is custody of the project’s share, not a governance vote: nothing can change the percentages.

Has the software been audited?

Not yet by an independent party, and we do not claim otherwise. The consensus and cryptography come from upstream Zcash software that has run real money for years, but reusing audited code does not audit the changes made around it. An independent review of exactly those changes is a gate on the road to mainnet, and it happens before launch, not after.

How private is it?

Privacy is a choice you make per payment. Shielded transactions keep sender, receiver and amount encrypted on-chain, using zero-knowledge proofs. Transparent transactions do not, and the wallet tells you which kind you are about to make.

Shielding protects what is written to the chain. It does not protect everything about how you use the network — for example, your own network connection is a separate matter.

Is this related to Ethereum Swarm or the Foursquare Swarm app?

No. SWARM has no connection to the Ethereum Swarm (BZZ) project or to Foursquare’s Swarm app. The logo is an original design.

How do I reach the project?

Write to swarmofficial@atomicmail.io or follow @swarm_coin on X (opens in a new tab). Together with this site and our GitHub, those are the only official channels. Anything else claiming to be SWARM — a sale, a presale, a listing, an airdrop — is not us.

We will never ask for your recovery words, private keys or a payment — not by email, not on X, not anywhere.
